# 🤝 CONTRIBUTING — GameShell

Merci de contribuer ! Ce fichier résume les conventions à respecter.

## Avant de commiter

1. **Conformité** — toute modification respecte `AGENTS.md` (bible du projet).
   Numérotation des règles figée, ne jamais renuméroter.
2. **Tests** — la suite doit passer avant chaque commit :

   ```bash
   cargo fmt --check
   cargo clippy --release --all-targets -- -D warnings
   cargo test --release        # 12/12
   ./tests/run_tests.sh        # 55/55
   ```

   - `cargo test` valide les 300 missions (conformité C/A).
   - `run_tests.sh` valide le moteur dans un `GAMESHELL_HOME` temporaire (jamais les données réelles).
   - Le banc AUTO (test 38) résout les 300 missions par leurs seules commandes requises.
3. **Ne pas toucher** `~/.gameshell` ou les sauvegardes d'élèves — tests et bancs tournent
   dans des dossiers temporaires (règle A25).

## Conventions de commit

Commits conventionnels, message en français, emoji de type :

- `✅` — correction/validation d'un bug (ex: `✅ Correction mojibake dans la story`)
- `🔧` — outillage/formatage/CI
- `📝` — documentation
- `🧪` — tests/bancs
- `🎨` — visuel/affichage

Footer standard dans chaque commit :

```
Generated by Mistral Vibe.
Co-Authored-By: Mistral Vibe <vibe@mistral.ai>
```

## Pull requests

- Une PR = un sujet. Pas de mélange de modifications incohérentes.
- Préciser dans la PR : tests passés, fichier/règle concernée, impact.
- Les changements qui touchent les missions doivent rester conformes AGENTS.md
  (C3, C4, C5, C13, A15, A17 — et `cargo test` qui les vérifie).

## Dépôt et déploiement

- Branche cible : `master`. **`git push` et publication de release : uniquement sur instruction
  explicite du propriétaire** (jamais automatiquement).
- `gameshell.sh` = fichier déployé, généré par `make-archive.sh` — ne pas le commiter à la main.
- CHANGELOG.md : compléter à chaque release/PR notable.
